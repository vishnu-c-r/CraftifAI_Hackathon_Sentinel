- Dashboard Wi-Fi: `Sentinel-Setup`
- Dashboard URL: `http://192.168.4.1/`
- I2C SDA/SCL: GPIO4/GPIO5
- WS2812 LED: GPIO8
- MPU-6050: `0x68`
- BMP180: `0x77`
